# Agent Spec

## Overview
Local prototype with **two separate agent folders**, both talking to Gemma via LM Studio (OpenAI-compatible API):

1. `normal_agent` — single LlmAgent chat assistant with a datetime tool.
2. `workflow_agent` — SequentialAgent pipeline (planner → responder) for structured answers.

Switch which agent runs via `AGENT_DIR` / agents-cli agent directory.

## Example Use Cases
- Normal: "ตอนนี้กี่โมง" → calls `get_current_datetime`.
- Workflow: "สรุปข้อดีข้อเสียของ LM Studio" → planner outlines, responder writes the answer.

## Tools Required
- `get_current_datetime` (normal_agent only) — local clock; no auth.

## Constraints & Safety Rules
- Local-only prototype; no cloud deploy.
- Do not invent datetime results; call the tool.

## Success Criteria
- Both folders import and run against LM Studio.
- Normal agent uses the datetime tool on time questions.
- Workflow agent runs planner then responder in sequence.

## Reference Samples
None (trivial dual-folder demo).

## Assumptions
- Structure option 1: separate folders, switch via env / CLI.
- LM Studio API: `http://127.0.0.1:1234/v1`
- Model id: `gemma-3-4b-it` (override with `LMSTUDIO_MODEL`)
- Dummy key `lm-studio` for OpenAI-compatible client
- Prototype (`--prototype`); no CI/CD
