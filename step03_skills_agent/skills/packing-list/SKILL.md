# Packing list

Write a checklist with `- [ ]` items, grouped under these headings:

- เอกสาร
- เสื้อผ้า (match the weather of the destination)
- ของใช้ส่วนตัว
- อุปกรณ์อิเล็กทรอนิกส์

Max 5 items per group. Answer in the user's language.
