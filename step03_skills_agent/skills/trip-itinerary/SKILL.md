# Trip itinerary

1. Ask for the city and number of days if the user did not say.
2. Write one section per day: `วันที่ 1`, `วันที่ 2`, ...
3. Each day has 3 parts: เช้า, บ่าย, เย็น. One place or activity per part.
4. End each day with one local food to try.
5. Keep it short. Answer in the user's language.
