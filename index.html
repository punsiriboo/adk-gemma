    背景：Local LLM 与 Gemma 4

    Background — local LLMs and the Gemma 4 model family

    什么是 Local LLM？

    本地模型（Local LLM）是直接在你自己的设备或服务器上运行的 AI 模型，而不是通过互联网调用云端 API。 A local LLM runs directly on your own device or server instead of calling a cloud API.

    App / Agent→localhost:1234 (LM Studio)→Gemma 4
    • 隐私：数据不离开本机 privacy
    • 离线：没有网络也能推理 works offline
    • 零调用费：无需按请求付费 no per-request cost
    • 可控：自由选择模型与参数 full control
    取舍 Trade-off

    本地推理受限于你的 RAM / GPU，模型越大越慢。先用小模型跑通流程。 Local inference is bound by your hardware — start small.

    Gemma 4

    Gemma 是 Google 推出的开放权重模型家族，可以下载到本地运行、微调，也可以部署到 Google Cloud。本 codelab 在 LM Studio 中使用： Gemma is Google’s open-weight model family. This codelab uses these LM Studio models:

    LM Studio model id说明 Notes
    google/gemma-4-e2b最轻量，适合内存较小的笔记本 · lightest
    google/gemma-4-e4b本 codelab 默认，平衡速度与质量，支持 tool calling · default
    google/gemma-4-26b更强推理，需要更多 RAM / GPU · strongest

    模型 id 以你的 LM Studio 中 lms ls 或 GET /v1/models 显示的为准。 Always copy the exact id your LM Studio reports.

    认识 ADK

    Agent Development Kit — an open-source, model-agnostic framework for building agents

    ADK 是 Google 开源的 Agent 开发框架，与模型无关。通过 LiteLlm 连接器，可以把 ADK 接到 LM Studio 中的本地 Gemma。 ADK is model-agnostic; the LiteLlm connector plugs it into local Gemma in LM Studio.

    编写第一个 Agent

    Point the agent at Gemma in LM Studio and give it a Python function tool

    用下面的代码替换 step01_basic_agent/agent.py 的全部内容： Replace the contents of step01_basic_agent/agent.py:

    step01_basic_agent/agent.py
    import datetime
from zoneinfo import ZoneInfo

from google.adk.agents.llm_agent import Agent
from google.adk.models.lite_llm import LiteLlm


def get_current_datetime(timezone: str = "Asia/Shanghai") -> dict:
    """Return the current date and time for a timezone, e.g. Asia/Shanghai or UTC."""
    now = datetime.datetime.now(ZoneInfo(timezone))
    return {"timezone": timezone, "datetime": now.strftime("%Y-%m-%d %H:%M:%S")}


model = LiteLlm(
    model="lm_studio/google/gemma-4-e4b",
    api_base="http://127.0.0.1:1234/v1",
)

root_agent = Agent(
    model=model,
    name="normal_gemma_agent",
    description="A helpful assistant for user questions.",
    instruction=(
        "Answer user questions to the best of your knowledge. "
        "Call get_current_datetime when asked about the date or time."
    ),
    tools=[get_current_datetime],
)

    代码解读 · Code walkthrough

    • lm_studio/：LiteLLM 的 LM Studio provider 前缀，后面接模型 id provider prefix + model id
    • api_base：LM Studio 本地服务地址 local server URL
    • get_current_datetime：普通 Python 函数就是工具；docstring 和类型注解告诉模型如何调用 a plain function is a tool
    • root_agent：ADK 通过这个名字找到入口 Agent the entry point ADK looks for
    💡 可选 Optional

    也可以不在代码里写 api_base，改为在 .env 中设置 LM_STUDIO_API_BASE=http://127.0.0.1:1234/v1。 You can set the base URL in .env instead.

    ⚠️ 注意 Note

    模型 id 必须与 /v1/models 返回的完全一致，否则会得到 404。 The id must match exactly, or you’ll get a 404.

    添加 MCP 工具：Airbnb 搜索

    Connect an MCP server with McpToolset — give Gemma a real Airbnb search

    复制上一步的文件夹，然后替换 agent.py：Copy the previous folder, then replace agent.py:

    Terminal
    cp -r step01_basic_agent step02_mcp_agent
node --version   # npx 需要 Node.js / npx needs Node.js
    step02_mcp_agent/agent.py
    from google.adk.agents.llm_agent import Agent
from google.adk.models.lite_llm import LiteLlm
from google.adk.tools.mcp_tool import McpToolset, StdioConnectionParams
from mcp import StdioServerParameters

airbnb_tools = McpToolset(
    connection_params=StdioConnectionParams(
        server_params=StdioServerParameters(
            command="npx",  # requires Node.js
            args=["-y", "@openbnb/mcp-server-airbnb", "--ignore-robots-txt"],
        ),
        timeout=30,  # first npx download can be slow
    ),
)

model = LiteLlm(
    model="lm_studio/google/gemma-4-e4b",
    api_base="http://127.0.0.1:1234/v1",
)

root_agent = Agent(
    model=model,
    name="travel_assistant",
    description="A helpful travel assistant.",
    instruction="Answer user questions. Use the Airbnb tools to find places to stay.",
    tools=[airbnb_tools],
)

    Workflow：planner → responder

    Chain two agents with an ADK 2.x Workflow and share data through output_key

    START→planner— state["plan"] →responder→Answer
    step03_workflow_agent/agent.py
    from google.adk.agents import Agent
from google.adk.models.lite_llm import LiteLlm
from google.adk.workflow import START, Workflow

model = LiteLlm(
    model="lm_studio/google/gemma-4-e4b",
    api_base="http://127.0.0.1:1234/v1",
)

planner = Agent(
    model=model,
    name="planner",
    description="Writes a short plan for answering the user.",
    instruction="Write a short numbered plan (3-5 steps) to answer the user. Do not answer yet.",
    output_key="plan",
)

responder = Agent(
    model=model,
    name="responder",
    description="Writes the final answer using the plan.",
    instruction="Use this plan:\n{plan}\n\nWrite the final answer for the user.",
)

root_agent = Workflow(
    name="workflow_gemma_agent",
    description="Planner then responder.",
    edges=[(START, planner, responder)],
)
    • output_key="plan"：planner 的输出写入 session state saves output to state
    • {plan}：responder 的 instruction 自动读取 state injected into the prompt
    • edges=[(START, planner, responder)]：按顺序执行的图 a sequential graph

    运行 adk web，选择 step03_workflow_agent，试试：Pick step03_workflow_agent and try:

    Prompt
    帮我安排一个成都周末两日游

    Events 中先看到 planner 的计划，再看到 responder 的最终回答；State 中有 plan。 Two agents run in order; plan shows in State.

    Skills：按需加载的能力包

    Give the agent reusable skills with SkillToolset — loaded progressively to save context

    Skill 是一个文件夹，里面的 SKILL.md 描述何时使用以及如何完成任务。Agent 先只看名称和描述，需要时才加载正文： A skill is a folder with a SKILL.md. The agent sees only name + description until it needs the full text:

    1. L1 list_skills：只看 name + description discover
    2. L2 load_skill：读取 SKILL.md 正文 load instructions
    3. L3 load_skill_resource：读取 references/ · assets/ load resources

├── __init__.py
├── agent.py
└── skills/

    skills/trip-itinerary/SKILL.md
    ---
name: trip-itinerary
description: Plan a day-by-day trip itinerary. Use when the user asks to plan a trip or what to do in a city for some days.
---

# Trip itinerary

1. Ask for the city and number of days if the user did not say.
2. Write one section per day: Day 1, Day 2, ...
3. Each day has 3 parts: morning, afternoon, evening.
4. End each day with one local food to try.
5. Keep it short. Answer in the user's language.
    step04_skills_agent/agent.py
    from pathlib import Path

from google.adk.agents.llm_agent import Agent
from google.adk.models.lite_llm import LiteLlm
from google.adk.skills import load_skills_from_dir
from google.adk.tools.skill_toolset import SkillToolset

skills = load_skills_from_dir(Path(__file__).parent / "skills")

model = LiteLlm(
    model="lm_studio/google/gemma-4-e4b",
    api_base="http://127.0.0.1:1234/v1",
)

root_agent = Agent(
    model=model,
    name="skills_agent",
    description="A travel helper that uses skills.",
    instruction="Answer user questions. Load a skill when it matches the request.",
    tools=[SkillToolset(skills=skills)],
)
